# AI Writer 0.1.2 · 修复安装版图标缺失 / Fix missing app icons in installed builds

> 延续独立发行线：应用身份（appId、productName、安装目录、更新通道）与旧版互不覆盖；
> Windows x64 发行线保持三项资产契约（安装包、blockmap、latest.yml）；安装包尚未进行代码签名；
> macOS 安装包仍顺延，后续版本恢复。
>
> This continues the independent line: the app identity (appId, productName, install directory, update channel)
> does not collide with older builds; the Windows x64 line keeps the three-asset contract (installer, blockmap,
> latest.yml); the installer is not code-signed yet; macOS installers remain deferred to a later release.

## 修复 / Fixes

1. 修复安装版中标题栏与状态栏应用图标不显示的问题：打包后的渲染进程以 file:// 加载页面，图标改用 Vite BASE_URL 拼接的相对地址，开发态与安装态都能正确解析。
   Fixed missing app icons in the title bar and status bar of installed builds: the packaged renderer loads pages from file://, so icons now resolve through Vite's BASE_URL instead of absolute paths.
2. 新增回归测试，禁止渲染层以绝对路径引用 public 资源，避免同类问题再次漏进安装包。
   Added a regression guard that forbids absolute public-asset URLs in the renderer so this class of bug cannot ship again.
