# AI Writer 0.1.6 · 助手提示词模块化与委派审稿对齐 / Assistant Prompt Modules & Delegated Review Alignment

> 延续独立发行线：应用身份（appId、productName、安装目录、更新通道）与旧版互不覆盖；
> Windows x64 发行线保持三项资产契约（安装包、blockmap、latest.yml）；安装包尚未进行代码签名；
> macOS 安装包仍顺延，后续版本恢复。
>
> This continues the independent line: the app identity (appId, productName, install directory, update channel)
> does not collide with older builds; the Windows x64 line keeps the three-asset contract (installer, blockmap,
> latest.yml); the installer is not code-signed yet; macOS installers remain deferred to a later release.

## 核心变更 / Core Highlights

### 1. 委派审稿与手动审稿对齐 / Delegated Review Matches the Manual Review
- **委派可指定审查维度**：项目助手委派审稿时可用 `review_dimensions` 点名维度（剧情连贯性、剧情合理性、角色状态、前后章节串联），与主界面「AI 审稿」弹窗勾选同源；点名维度优先深查，其余维度仍全面覆盖。
  Delegated review can name review dimensions, sharing one catalog with the AI review dialog; named dimensions get priority, while delegated review still covers the rest.
- **委派审稿可靠性补齐**：委派前自动保存作者当前草稿，保存失败即中止委派；目标仓库校验草稿版本，报告必须绑定最新稿，避免旧稿评审被当作有效结果。
  Delegation now saves the open draft first and aborts on failure; the report is bound to the newest draft version, so stale reviews can no longer pass as valid.

### 2. 助手提示词模块化与设置页 / Editable Prompt Modules & Assistant Settings
- **提示词拆分可编辑模块**：四个助手的系统提示拆分为独立模块（身份、工作规约、工具规约等），生成后由提示词回归测试守护，改文案不再牵动整段巨型模板。
  Assistant prompts are split into independent modules with regression coverage, so editing copy no longer means touching one giant template.
- **本项目设置页**：新增「本项目」下的助手设置页，展示组装后的系统提示与模块清单，逐项即时自动持久化，并支持切换到任意助手查看共享硬性规则。
  Added an assistant settings page that previews the assembled system prompt and module list, auto-saving each change.

### 3. 助手工具闭环 / Agent Tool Closure
- **叙事线程读写闭环**：新增叙事线程读取与写入工具，主助手可直接核对主线、支线推进状态并提交变更。
  Narrative threads can now be read and updated through domain tools.
- **草稿历史与报告回读**：补上草稿修订历史读取、报告与文件回读工具，减少助手凭记忆推断事实。
  Added draft revision history and read-back tools so assistants verify facts instead of inferring them.

### 4. 编辑器与界面细节 / Editor & UI Details
- **一章一条草稿、工具栏切版本**：草稿列表每章只保留一个入口，历史版本在工具栏切换，版本下拉位置固定不再跳动；移除编辑器里的直接 AI 修稿入口。
  One draft entry per chapter with version switching in the toolbar, and the direct AI revision entry is gone.
- **界面收敛**：标题栏汉堡按钮改为真正的主菜单并收敛设置入口，状态栏展示版本号，修复会话行悬停跳动。
  Cleaned up the title bar menu, showed the version in the status bar, and fixed conversation rows jumping on hover.
