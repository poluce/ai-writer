# AI Writer 0.1.3 · 更新检查按标准规则运行 / Standard update-check rules

> 延续独立发行线：应用身份（appId、productName、安装目录、更新通道）与旧版互不覆盖；
> Windows x64 发行线保持三项资产契约（安装包、blockmap、latest.yml）；安装包尚未进行代码签名；
> macOS 安装包仍顺延，后续版本恢复。
>
> This continues the independent line: the app identity (appId, productName, install directory, update channel)
> does not collide with older builds; the Windows x64 line keeps the three-asset contract (installer, blockmap,
> latest.yml); the installer is not code-signed yet; macOS installers remain deferred to a later release.

## 更新检查规则 / Update-check rules

1. 应用长时间运行时，每 30 分钟触发一次自动复查，实际联网频率不超过每小时一次；发现新版本立即提醒。
   While the app keeps running, an automatic recheck fires every 30 minutes, with at most one network check per
   hour; a newly published release is surfaced immediately.
2. 自动检查失败后按 15 分钟 → 1 小时 → 6 小时指数退避，成功一次即重置，避免反复请求。
   Failed automatic checks back off exponentially (15 minutes → 1 hour → 6 hours) and reset after one success.
3. 启动检查仍遵循每天最多一次；手动「检查更新」不受任何频率限制。
   The startup check still runs at most once per day; the manual "Check for updates" action is never rate-limited.
4. 下载中或已下载待重启时不再自动检查，避免打断用户；其余提醒、下载、重启门禁规则保持不变。
   No automatic checks run while a download is in progress or an update is waiting for restart; all reminder,
   download, and restart-guard rules stay unchanged.
