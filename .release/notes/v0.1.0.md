# AI Writer 0.1.0 · 独立发行线首版 / First release of the independent line

> 本仓库从上游 GPL-3.0 代码派生后已独立演进：应用身份（appId、productName、安装目录、
> 更新缓存目录、更新通道）与旧版互不覆盖，版本号自 0.1.0 重新起算。
>
> This repository derives from upstream GPL-3.0 code and now ships independently. The app
> identity (appId, productName, install directory, updater cache directory, update channel)
> no longer collides with older builds, and versioning restarts at 0.1.0.

## 新功能 / New features

1. 项目助手可把任务委派给架构助手与章节蓝图助手；目标助手会话优先复用，忙碌时按 FIFO 排队，不新建碎片会话。
   The project assistant can delegate work to the architecture and chapter-blueprint assistants; their sessions are reused and queued FIFO when busy instead of spawning fragmented conversations.
2. 工具确认点击后立即把卡片翻到执行中，并按工具卡所属会话回传确认；架构/蓝图助手不再把批准发错会话。
   Approving a tool flips its card to running immediately and routes the confirmation back to the conversation that owns the card, so architecture and blueprint assistants no longer send approvals to the wrong session.
3. 情节大纲补齐分卷标题与章节区间解析，第二、三、四卷不再被并入前一章的章节区间。
   Synopsis parsing now understands volume headings with embedded chapter ranges, so later volumes are no longer merged into the preceding chapter range.
4. 左侧目录改为分卷活页标签树：分卷标签可拖拽调序，目录宽度可拖动并持久化记忆。
   The table of contents is now a notebook-style volume tab tree: volume tabs can be reordered by dragging, and the pane width is draggable and remembered.
5. 故事架构统一为 前提 → 环境 → 情节 → 人物，设定按分段卡片渲染并支持原地编辑。
   Story architecture follows premise → setting → plot → characters, and settings render as section cards that stay editable in place.

## 修复 / Fixes

1. 修复工具确认后界面长时间无反馈的问题。
   Fixed the long silence between approving a tool and any visible state change.
2. 修复架构/蓝图助手的确认被发往通用助手会话、导致工具永久等待的问题。
   Fixed confirmations from architecture/blueprint assistants being sent to the general conversation and leaving tools waiting forever.
3. 修复分卷标题之后的章节内容被错误归入上一条章节区间的问题。
   Fixed chapter content after a volume heading being attached to the previous chapter-range card.

## 安装提示 / Installation notice

- 三项资产契约：Windows x64 安装包、增量 blockmap 与 `latest.yml`。macOS 安装包在本版本暂不发布，后续恢复后仍按 ARM64 / Intel 分别发布。
  Three-asset contract: the Windows x64 installer, its blockmap, and `latest.yml`. macOS installers are deferred for this version; when restored they will ship as separate ARM64 and Intel builds.
- Windows 安装包尚未进行代码签名，首次安装或更新时可能出现 SmartScreen 提示，请核对下载来源后放行。
  The Windows installer is not code-signed; SmartScreen may warn on first install or update. Verify the download source before continuing.
- 由于应用身份已变更，从旧版升级需要手动安装一次本版本，之后由本仓库的更新通道接管。
  Because the app identity changed, upgrading from an older build requires one manual install of this version; this repository's update channel takes over afterwards.
