# AI Writer 0.1.1 · 全局更新提醒直达下载与重启 / Global update reminder with one-click download and restart

> 延续独立发行线：应用身份（appId、productName、安装目录、更新通道）与旧版互不覆盖；
> Windows x64 发行线保持三项资产契约（安装包、blockmap、latest.yml）；安装包尚未进行代码签名；
> macOS 安装包仍顺延，后续版本恢复。
>
> This continues the independent line: the app identity (appId, productName, install directory, update channel)
> does not collide with older builds; the Windows x64 line keeps the three-asset contract (installer, blockmap,
> latest.yml); the installer is not code-signed yet; macOS installers remain deferred to a later release.

## 更新提醒 / Update reminder

1. 发现新正式版后，常驻提醒直接提供「下载更新 / 打开下载页」与「稍后提醒」；点击即开始下载，无需再跳转到更新卡片。
   When a new stable release is found, the persistent reminder directly offers "Download update / Open download page"
   and "Remind me later"; downloading starts on click without jumping to the update card.
2. 下载完成后同一条提醒切换为「重启更新」；重启前先校验创作任务与未保存编辑，取消门禁后提醒自动恢复。
   Once downloaded, the same reminder switches to "Restart and update"; active creative tasks and unsaved edits are
   checked before restarting, and the reminder returns automatically if the guard is cancelled.
3. 下载失败按错误类型给出「重试」动作；「稍后提醒」按 7 天延后，到期后自动恢复。
   Failed downloads offer a retry action; "Remind me later" defers for 7 days and returns automatically after expiry.
4. v0.1.0 安装的用户将收到本版本提醒；旧版提醒入口为「查看更新」，仍可正常完成升级。
   Installs on v0.1.0 receive this reminder; the older entry reads "View update" and still upgrades normally.
