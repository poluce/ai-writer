# AI Writer 0.1.5 · 设计 v2 界面重构与审稿主工作区闭环 / Design v2 UI & Review Workspace Lifecycle

> 延续独立发行线：应用身份（appId、productName、安装目录、更新通道）与旧版互不覆盖；
> Windows x64 发行线保持三项资产契约（安装包、blockmap、latest.yml）；安装包尚未进行代码签名；
> macOS 安装包仍顺延，后续版本恢复。
>
> This continues the independent line: the app identity (appId, productName, install directory, update channel)
> does not collide with older builds; the Windows x64 line keeps the three-asset contract (installer, blockmap,
> latest.yml); the installer is not code-signed yet; macOS installers remain deferred to a later release.

## 核心变更 / Core Highlights

### 1. 浅色默认与设计 v2 界面重构 / Light Default Theme & Design v2 UI
- **浅色主题为默认基准**：默认主题切至浅色（`light`），全面落地设计 v2 视觉令牌（背景 `#F4F6F9`、面板 `#FAFBFC`、主色 `#3B6FE0`、圆角系统收敛，弱化文字满足 WCAG AA 4.5:1 对比度标准），消除暗色闪跳。
  Switched default theme to light mode and landed design v2 visual tokens with accessible WCAG AA contrast.
- **助手切换器整合**：写作、架构、蓝图、审稿、输出并入助手面板头部，移除旧版右侧 30px 工具栏；标题栏降噪并将菜单收口，修复菜单被主区层级遮挡的问题。
  Consolidated assistant modes into the assistant panel header, removing the redundant right toolbar; cleaned up the title bar and fixed menu overlay z-index stacking.
- **统一入口与底部常驻页签**：合并「首页」与「项目」为单一入口，无项目时呈现引导，有项目时直达小说配置；任务、日志、模型调用等状态面板收拢至主区底部常驻页签条。
  Merged Home and Project into a unified entry point, and docked secondary panels (Tasks, Logs, Model Calls) to a persistent bottom tab strip.

### 2. 审稿报告主工作区与生命周期闭环 / Review Report Workspace & Lifecycle Closure
- **双栏交互审稿原稿视图**：审稿报告移入主工作区，提供「带行号与编号批注的原稿视图」与「总览/分类看板」，支持行内批注与卡片双向高亮定位、条目原地编辑与手动追加。
  Upgraded review reports into the main workspace with a dual-pane annotated draft view and categorized review board, featuring bidirectional anchor positioning.
- **侧栏挂载与生命周期管理**：侧栏章节草稿节点下挂审稿报告，支持查看严重度摘要、右键打开与删除；主智能体挂载 `manage_review_reports` 与受保护的 `delete_review_report` 工具，修稿定稿后自动完成收尾。
  Integrated review reports under chapter draft trees in the sidebar, with automated lifecycle management and cascade cleanup upon revision completion.
- **只增不减数据治理**：调用日志限制保留最近 1000 条并支持可视化清空；恢复候选处理即清理；导入运行历史支持查看与清理；后处理记录只保留最新同源 run。
  Introduced data governance policies to prune unbounded logs, import runs, post-process records, and temporary candidate snapshots.

### 3. 诊断日志治理与通用幂等收据 / Diagnostic Logging & Unified Idempotency Keys
- **自然日日志轮转**：日志按本地自然日自动拆分为 `vela-YYYY-MM-DD.log`，单文件超 5MB 自动分片，保留最近 14 天并移除高频流水账 info，保留关键排错链路。
  Implemented date-based log rotation (`vela-YYYY-MM-DD.log`) with 5MB chunking and 14-day retention.
- **通用幂等收据表**：新增通用 `idempotency_keys` 事实表，统一承载写操作幂等保护并在项目打开时自动迁移旧四张领域收据表。
  Consolidated multiple legacy receipt tables into a unified `idempotency_keys` table with seamless idempotent migration.
