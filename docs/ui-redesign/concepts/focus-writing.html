第三章　记忆修复师

3,240 字 上次编辑 14:32 目标 3,000

凌晨四点，雾城的记忆修复局还亮着三盏灯。林见夏把最后一张纸页压进扫描台时，指尖沾上了墨，黑得很不自然，像是从纸里渗出来的。

系统显示这条记忆属于一位七十三岁的钟表匠，内容是一段从未发生过的婚礼。可修复记录里，这张纸已经被调阅过两次，时间戳都是明天。

她想起妹妹失踪那天，档案室的门也是开着的。地上同样落着一张纸，正面是空白，背面写着两个字：别回头。

档案室的恒温系统发出低鸣。她把扫描台推到窗边，借自然光比对纸纤维的走向——这是修复课第一年学的手法，也是唯一骗不过系统的办法。

扫描完成的那一刻，屏幕上的修复合集自动跳出一行小字：修复次数 3。林见夏盯着那行字，指尖的墨迹慢慢干了。

林见夏把纸翻过来，指尖在“别回头”三个字上停了三秒。窗外的潮声漫上来，她忽然意识到，这不是提醒，是警告——而写下它的人，很可能就是明天的自己。
