## 一、设计判断

现状的问题是**结构问题，不是配色问题**：

1. 五条纵向分区（左栏 72 / 侧栏 248 / 编辑区 / 助手 320 / 右栏 30），1440 宽下编辑区只剩约 750px；
2. 右栏那 30px 只放 5 个图标，却独占一条分区；
3. 同名不同义：左栏「架构 / 蓝图」进编辑器，右栏「架构 / 蓝图」进 AI 助手；
4. 左栏 11 项、行高 66px，938px 可用高度里几乎占满，且「任务 / 日志 / 模型」本是底部面板的 tab；
5. 页面底 `#F7F8FA` 与面板 `#F9FAFB` 只差 2 阶，分区全靠 1px 灰线，浅色下很平；
6. 三处空态说同一句话（侧栏「未打开项目」、主区「请先打开项目」、助手「打开项目后可用」）；
7. 字号 10.5 / 11 / 11.5 / 12 / 12.5 / 13 六档混用。

## 二、七处改动

| # | 改动 | 解决什么 |
| :--- | :--- | :--- |
| 1 | 标题栏只留 新建 / 打开 / 更多；导入原稿、拆解仿写、导出、备份收进「更多」；主题改为「浅色 ⌄」菜单 | 标题栏 8 个同级动作没有层级；四主题单图标循环不可发现 |
| 2 | 左栏只留内容维度（首页/项目/架构/情节/蓝图/剧情/人物/知识库 + 设置），11 → 9 项，行高 66 → 54 | 左栏挤；任务类入口混进内容导航 |
| 3 | 表面层级：页面底 `#F4F6F9`、侧栏 `#FAFBFC`、内容面 `#FFFFFF`，一档极轻投影 | 浅色下分区不清晰 |
| 4 | 空态收口：主区唯一引导（新建 / 打开 / 拆解 / 最近项目），侧栏不再重复 | 三处同义空态 |
| 5 | 助手切换器（写作 / 架构 / 蓝图 / 审稿 / 输出）并入助手面板头部，删掉 30px 右栏 | 省一条分区；消除同名不同义 |
| 6 | 助手空态给动作：一句说明 + 新建 / 打开两个按钮 | 「打开项目后可用」是死胡同 |
| 7 | 底部 任务 / 日志 / 模型调用 常驻 tab（折叠后保留） | 与左栏职责分离 |

附带：字号收到 `11 / 12 / 13 / 20` 四档，圆角 `6 / 8 / 10 / 14`，间距按 4 的倍数；模型选择器把思考等级写成独立 chip「思考 关」，不再是一个孤零零的「关」字。

## 三、小说配置页（按真实结构重做）

第一版配置页用的是旧布局，已按当前代码与实机截图重做：

| 项目 | 第一版（错） | 现在（对照真实页面） |
| :--- | :--- | :--- |
| 分区形态 | 每段一张独立卡片 | 基本信息一张分组卡 + 7 个文档式分区（细分割线，非卡片） |
| 顶部动作 | 保存 + AI 填充配置 | 仅「保存」；AI 生成在每段分区上 |
| 分区数量 | 3 段 | 7 段：核心大纲 / 世界观 / 金手指 / 主角人设 / 全局写作要求 / 文风配置 / 参考作品 |
| 基本信息字段 | 只画 6 个 | 9 个：类型、细分类型、目标受众、故事结构ⓘ、叙事视角ⓘ、总章数、每章字数、写作语言ⓘ、沉寂提醒阈值ⓘ + 恢复默认 |
| 段落正文 | 楷体 14.5px | 界面字体 13px / 1.75（配置文本不是小说正文） |
| 标签页 | 无溢出控制 | 右侧 ‹ › ⋯ |

v2 在这页只改三件事：表面层级（页面底 `#F4F6F9` / 内容面白 / 分组卡 `#F7F9FB`）、字号收敛（分区标题 16 → 14，动作按钮对齐同一基线）、输入框圆角与边框统一。

落地时与设计稿的三处偏差，都以「真实可用」为准：

1. **弱化文字取 `#5F6773` 而非 `#6B7280`**：后者在 `--color-active` 上只有 3.90:1，低于 AA；`#5F6773` 为 4.61:1，仍比次级文字 `#4A5160` 浅一档。
2. **助手切换器在窄面板下只留图标**：默认分栏把右栏压到 160–200px 时，五个「图标+文字」会被挤成省略号，因此用 `ResizeObserver` 在 < 268px 时收起标签。
3. **底部页签条在面板收起时常驻在主区下方**，不占用左侧内容导航；`任务/日志/模型调用` 三个入口从左侧栏移除，左栏只剩内容维度。

另外修掉一个真实缺陷：标题栏与主区域都是 `.app-skin-root` 的直接子元素、默认同为 `z-index:1`，主区域在 DOM 中靠后会把下拉菜单整块盖住——下拉菜单原先在真实应用里完全不可见。现已在根层级单独把标题栏抬到 `z-index:30`。
