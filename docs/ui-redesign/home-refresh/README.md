# 主页面改版 v1

针对「开始一部长篇」启动页的改版提案与落地实现，对应 critique 里的 P1/P2 问题。设计稿用纯 HTML/CSS 绘制，可直接在浏览器打开对照评审，不参与生产构建；实现部分已进入生产代码。

## 文件

- `home.html`：两种状态的交互稿，顶部「预览状态」可切换
- `preview-home.png` / `preview-first.png`：设计稿的两种状态（1440×900）
- `impl-home.png` / `impl-first.png` / `impl-home-1024.png`：生产实现的对应截图（1440×900、1024×768）

## 关键改动

1. **继续写作成为主结构**：有最近项目时，最近一本书占据页面唯一的主卡——书名（衬线体）、当前章、总字数、进度、上次写到的一段正文；「继续写作」是唯一实心主按钮。
2. **三扇门降级**：新建/打开/拆解仿写收进右侧「开始」栏，新建保留快捷键提示（Ctrl N / Ctrl O）；首次使用时才把「新建项目」升为主按钮。
3. **最近项目变得可用**：整行 54px 都可点击，行内给出「第几章 · 字数 · 所在文件夹」，右侧「⋯」菜单常驻可见（不再只依赖悬停），可访问名带上项目名，列表使用 role=list。
4. **空侧栏收起**：无项目时不渲染项目结构面板，左栏只保留「项目 / 设置」，工作区在打开项目后解锁。
5. **模型就绪状态前置**：「开始」栏底部直接显示模型是否就绪；没有模型时给出「去设置」入口，不再让作者建完项目才发现。
6. **版式随窗口生长**：内容列宽 1080px、桌面上居中；书名/开场标题 29–34px，正文 12–13px，时间戳 11px；宽屏不再是一张缩在中间的 512px 手机卡。

## 数据来源

章节、字数、进度与「上次写到」摘录来自主进程写入 `~/.vela/recent-projects.json` 的轻量快照（`RecentProjectSnapshot`）：项目打开/保存时由 `DraftRepository.getLauncherSummary()` 汇总各章最新草稿，启动页无需打开项目库。旧记录没有快照时自动退回「项目名 + 最近时间」的旧版信息，不做假数据填充。

## 预览

设计稿直接双击 `home.html`；字体从仓库 `public/fonts/` 本地加载，无需启动服务。实现截图由 dev server（`http://127.0.0.1:5180/`）在 1440×900 / 1024×768 下截取。
