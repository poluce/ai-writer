> 状态：方向待选定

## 1. 设计目标与原则

当前界面的问题不是"颜色不好看"，而是**视觉层级没有建立**：卡片、面板、页面底共用同一档背景与边框，字号散落成 11 档，强调色同时承担五种语义。因此重构顺序固定为：层级 → 排版 → 密度 → 颜色 → 装饰。

五条原则：

1. **层级优先**：靠表面明度与投影分出"底 / 面 / 浮"三层，而不是给所有东西描边。
2. **字先于色**：字号、字重、行高承担主要层级；颜色只做语义辅助。
3. **强调色预算**：每屏实心强调色不超过 2 处（主 CTA + 品牌标记），其余选中态用浅底 + 指示条。
4. **4px 栅格**：间距只取 4 的倍数；控件高度只允许 28 / 32 / 36 三档。
5. **一个语义一种实现**：一套按钮、一套卡片、一套表单，禁止并列的 CSS 类与内联样式重复实现。

## 2. 设计令牌（Token）架构

令牌分三层，组件只消费第二、三层：

| 层 | 内容 | 谁改 |
| :--- | :--- | :--- |
| 1. 色板 palette | 每个方向一套原始色值 | 主题切换时整包替换 |
| 2. 语义 semantic | surface / line / text / accent / elevation / state | 主题与皮肤只替换这一层 |
| 3. 组件 component | 控件尺寸、圆角、间距、字阶 | 全局固定，方向之间不差异化 |

### 2.1 语义颜色

| 令牌 | 含义 | paper 基准值 |
| :--- | :--- | :--- |
| `--surface-canvas` | 页面底 | `#F6F1E4` |
| `--surface-panel` | 侧栏、面板、底部面板 | `#EFE8D6` |
| `--surface-card` | 卡片、浮层、输入底 | `#FDFBF4` |
| `--line-subtle` | 极细分割线 | `color-mix(in srgb, #2A2521 10%, transparent)` |
| `--line-strong` | 输入框、控件边框 | `color-mix(in srgb, #2A2521 16%, transparent)` |
| `--text-primary` | 正文标题 | `#2A2521` |
| `--text-secondary` | 次级文字、字段标签 | `#5A524A` |
| `--text-muted` | 说明、元信息 | `#6C6455` |
| `--accent-solid` | 主 CTA、品牌标记 | `#B5402C` |
| `--accent-soft` | 选中底、AI 动作底 | `rgba(181,64,44,.08)` |
| `--accent-text` | 浅底上的强调文字 | `#96402C` |
| `--on-accent` | 实心强调上的文字 | `#FFF7EE` |

### 2.2 字阶（只允许 7 档）

| 令牌 | 字号 | 行高 | 用途 |
| :--- | :--- | :--- | :--- |
| `--fs-caption` | 11px | 1.45 | 元信息、状态栏、badge |
| `--fs-label` | 12px | 1.5 | 字段标签、树节点 |
| `--fs-body` | 13px | 1.6 | 正文、卡片描述、输入值 |
| `--fs-title` | 14px | 1.4 | 卡头标题、面板标题 |
| `--fs-heading` | 16px | 1.35 | 页面主标题 |
| `--fs-display` | 20px | 1.3 | 工作台页面标题 |
| `--fs-hero` | 24px | 1.25 | 欢迎页、空白页主张 |

规则：禁止 `text-[0.68rem]` 这类任意字号；中文不使用 `uppercase` 与字距；数字统一 `font-variant-numeric: tabular-nums`。

### 2.3 间距 / 圆角 / 尺寸

| 类别 | 允许值 |
| :--- | :--- |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 |
| 圆角 | 4（标签）/ 6（控件）/ 8（面板）/ 10（卡片）/ 12（弹窗） |
| 控件高度 | 28（sm）/ 32（md）/ 36（lg） |
| 图标 | 16 / 18 / 20，统一 `lucide`、stroke 1.75 |
| 布局尺寸 | 标题栏 44 / 标签页 38 / 行高 30 / 状态栏 26 |

### 2.4 投影（三级）

- `elev-1`：卡片、列表悬浮项，近乎不可见，只提供微弱分离；
- `elev-2`：下拉、浮层、AI 输入卡；
- `elev-3`：弹窗、设置面板，需要背景压暗。

浅色方向投影必须带暖/冷底色偏移，而不是纯黑透明度；深色方向用内高光 + 深投影。

### 2.5 动效

只保留两档：`120ms`（hover / press）、`200ms`（浮层进入）。曲线统一 `cubic-bezier(0.16, 1, 0.3, 1)`。禁止弹簧、发光呼吸、无意义位移。

## 3. 三套方向对比

| | A 纸墨书卷 2.0 | B 中性专业 IDE | C 深色创作舱 |
| :--- | :--- | :--- | :--- |
| 关键词 | 书卷、宣纸、朱砂印 | 冷静、线性、工具 | 暗房、暖光、沉浸 |
| 标题字体 | 思源宋体 600 | Inter / 思源黑 600 | Inter / 思源黑 500 |
| 正文字体 | Inter + 思源黑 13px | Inter + 思源黑 13px | Inter + 思源黑 13px |
| 圆角 | 卡片 10 / 控件 7 | 卡片 6 / 控件 6 | 卡片 8 / 控件 6 |
| 投影 | 暖色柔投影 | 基本不用，靠 1px 线 | 深色内高光 + 深投影 |
| 密度 | 中 | 高（左栏图标化、行高 28） | 中 |

## 5. 组件规范

### 5.1 标题栏（44px）

- 结构：品牌标记 25px + 产品名 + 项目名 + 保存态 + 分隔线 + 低频动作 + 右侧工具 + 窗口控制。
- 品牌标记是全屏唯一的实心强调色方块（25px，圆角 7）。
- 低频动作（备份、导出、新建、打开）统一 28px 高、图标 14px、间距 2px；组间用 1px 分隔线。
- 搜索、缩放、语言、主题收敛为 28px 图标按钮；窗口控制 26px。
- 禁止：在同一行混放三个字号、在标题栏放彩色状态标签。

### 5.2 左侧主导航

- 方案 A/C：64px，图标 19px + 标签 10px，行高 53px；选中 = 浅底圆角 8 + 左缘 3px 强调条 + 强调色图标。
- 方案 B：52px，纯图标 18px，行高 38px，选中 = 浅底圆角 + 强调色图标，`title` 提供提示。
- 分组间距：主功能组与底部工具组之间用弹簧撑开；"设置"与工具组之间用 1px 分隔线。

### 5.3 侧边栏（238 / 226px）

- 头部 44px：标题 12px/600 + 折叠按钮。
- 树节点行高 30px（B 为 28），图标 15px，右侧元信息 10.5px muted。
- 选中行 = 强调浅底 + 强调文字 + 图标强调；不使用整行深色块。
- 分组行 12.5px/500，子级缩进 28px（B 为 30px）。

### 5.4 标签页（38px）

- A/C：圆角上沿标签，选中页背景并入内容区，顶部 2px 强调线；
- B：扁平下划线，2px 强调线贴底；
- 关闭按钮 13px，默认 70% 透明，hover 全显。

### 5.5 页面头

- 标题 20–22px（A serif / B 18px sans / C 20px sans），副标题 11.5px muted，间距 5px。
- 右侧动作区：主 CTA 一个（实心），次动作 outline；高度 30px。

### 5.6 卡片

- 默认：`surface-card` + 圆角 10 + `elev-1`，**不描边**；方向 B 例外，用 1px 线、无投影。
- 内边距：17px 20px 19px（B 15px 16px）。
- 卡头：标题 15px serif/600（B 13.5px sans）+ 描述 11.5px muted，卡头下间距 14px。
- 卡片间距 16px（B 12px）；页面首卡不额外加 margin-top。

### 5.7 表单

- 标签 11.5px/500 secondary，下间距 6px（B：11px muted / 5px）。
- 控件高度 32px，圆角 7，背景 `surface-card` 或略暗一档，边框 `line-strong`。
- 多行文本域高 84px（B 76px），行高 1.75。
- 禁用态：opacity 0.45 + `cursor-not-allowed`，禁止只变灰无提示。

### 5.8 按钮

四类：primary（实心）/ secondary（描边）/ ghost（无底）/ AI（浅底 + sparkles）。
三档尺寸：28 / 30 / 32（sm 26 用于卡片内）。

- 实心按钮整屏只允许出现在主 CTA；AI 按钮默认浅底，卡片内不使用实心强调色。
- 主按钮与 AI 按钮都可带 `elev` 投影，但只在浅色方向；深色方向用发光减法。
- 图标 14px，文字与图标间距 6px；禁止图标单独放大到 20px 以上。

### 5.9 空状态

- 图标 40–48px、stroke 1.5、muted；标题 13.5px/600；说明 11px muted；最多一个主 CTA。
- 禁止给整块内容加 `opacity: 0.3`（现状 EmptyState 即如此），改用颜色与留白。

### 5.10 AI 助手面板（286–298px）

- 头部 44px：标题 12px/600 + 计划/写作分段控件（胶囊，选中实心强调）+ 更多按钮。
- 空态：42px 圆角方形图标底 + 标题 13.5px + 说明 11px + 三条建议胶囊。
- 输入卡：圆角 10、`elev-2`、内边距 9–10；底部 chip 行（附件 / 深度 / 模型）+ 28px 发送按钮。

### 5.11 底部面板（142–150px）

- 页签行 34px，选中页签 11.5px/600 + 2px 强调下划线；空态图标 15px + 说明 11.5px muted，垂直居中。

### 5.12 状态栏（24–26px）

- 左：版本 + 项目名 + 保存态；右：字数 / 编码 / 模型。
- 字号 10.5px，`tabular-nums`，分隔符 1px；禁止放可点击的强交互。

### 5.13 设置弹窗（964 × 604）

- 左侧导航 218px（B 206px）：标题 12.5px/600 + 10 个设置项，行高 38px（B 34px），选中 = 浅底 + 强调文字。
- 右侧：头部 22px 内边距（标题 16.5px serif / B 15px sans + 描述 11.5px）、分割线、工具栏、内容区 24px 内边距。
- 模型卡片：34px 图标底 + 名称 13px/600 + 默认标签（浅底描边胶囊）+ 参数行 11px muted + 编辑/更多图标。
- 底部提示条：虚线描边 + 11px muted，固定贴底。
- 遮罩：背景压暗 30–58%，弹窗投影 elev-3。

## 6. 字体与排版

- UI 字体：Inter（拉丁/数字）+ 思源黑体（中文）；写作区：霞鹜文楷 / 思源宋体，保留用户可配置。
- 中文正文 13px / 1.6；说明文字 11.5–12px / 1.5；标题禁止全大写与字距。
- 数字（字数、章节号、版本）统一 `tabular-nums`，避免跳动。
- 写作区建议：字号 17px、行高 1.8、段距 0.6em、行宽 32–38 汉字，首行缩进可配。
- 最小可读字号 11px；低于 11px 只允许出现在 badge 与状态栏元信息。

---

## 7. 无障碍与交互状态

- 正文对比度 ≥ 4.5:1，大字号 ≥ 3:1（上表已实测）。
- 焦点环：2px 强调色 + 1px offset，禁止仅靠背景色变化表达焦点。
- hover / active / disabled 三种状态必须同时改变至少两个属性（底色 + 文字色，或边框 + 投影）。
- 颜色不单独承载信息：状态标签需同时有文字；错误态需有图标或文案。
- 动效尊重 `prefers-reduced-motion`。

## 8. 落地路径

| 阶段 | 内容 | 预估 |
| :--- | :--- | :--- |
| P0 | 令牌层（表面/线条/字阶/间距/圆角/投影）+ 主题对比度修正 | 1–2 天 |
| P1 | 原语组件：Button / Input / Textarea / Card / Badge / Tabs / Dialog / EmptyState | 2 天 |
| P2 | 布局壳：标题栏 / 左栏 / 侧栏 / 标签页 / AI 面板 / 底部面板 / 状态栏 | 2 天 |
| P3 | 页面试点：小说配置页 + 设置弹窗 + 欢迎页 + 正文编辑器 | 2–3 天 |
| P4 | 全量铺开 + 视觉回归 | 按页面数量评估 |

验收方式：

1. `tsc --noEmit` 0 错误；
2. 相关 Vitest / Browser Mode 测试通过；
3. Storybook 新增 "Visual System" 页（色板 / 字阶 / 间距 / 表面层级 / 组件状态）；
4. 三个代表页面的 before/after 截图对比；
5. 对比度脚本检查所有主题的正文与 muted 组合。

迁移纪律：

- 先删并列实现（`.btn-primary` / `.writer-primary-button` / `.writer-command-button` 收敛为一套）；
- 内联 `style={{ color }}` 逐步换成 token 类；
- 不新增任意值类（`text-[13px]`、`bg-[#...]`）。

## 9. 本轮不做

- 不调整信息架构与导航分组（只做视觉与密度）；
- 不引入新的 UI 库或图标库；
- 不做毛玻璃、霓虹光晕、渐变炫技、Emoji 装饰；
- 不改动编辑器交互与业务逻辑。
